# ai-playground

Learning to build with LLMs (Gemini first), step by step.

## Setup

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # then put your real GEMINI_API_KEY in .env
```
